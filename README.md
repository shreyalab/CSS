# 🛒 Amazon Clone (HTML & CSS)

A beginner-friendly clone of the Amazon homepage built using **HTML5**
and **CSS3** to practice front-end development fundamentals.

> 🚀 This project is created for educational purposes to improve layout,
> styling, and design skills.

## 🎯 Learning Objectives

This project helped in understanding:

-   Structuring webpages using semantic HTML
-   Using Flexbox for layout alignment
-   Creating grid-like sections
-   Styling buttons and links
-   Working with background images
-   Applying hover effects
-   Understanding CSS Box Model (margin, padding, border)

------------------------------------------------------------------------

## 🚀 How to Run the Project

1.  Clone the repository:

    ``` bash
    git clone https://github.com/your-username/amazon-clone.git
    ```

2.  Open the project folder.

3.  Open `index.html` in your browser.
